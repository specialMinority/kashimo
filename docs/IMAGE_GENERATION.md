# Kashimo 캐릭터 아이콘

- 생성: 내장 ImageGen (CLI/API 키 사용 없음)
- 참조: 사용자 Photo 1 / Photo 3의 회백색 장모 고양이.
- 생성 원본: `assets/branding/mascot-source.png`
- 앱 아이콘: `assets/branding/icon.png`, `mascot.png`, `adaptive-icon.png`
- 실사 배경: `assets/branding/cat-tower.jpg` (Photo 3), `cat-cozy.jpg` (Photo 4). 원본 그대로 복사, UI에서 cover 배치.
- 앱 아이콘 파생물은 크기 변환과 여백만 조정.

## 최종 프롬프트

```text
Use case: logo-brand.
Asset type: final square app icon and in-app mascot for Kashimo, a modern friendly personal lending/borrowing ledger.
Input images: supplied cat photos are subject reference images, not backgrounds to reproduce.
Primary request: create a very cute, premium illustrated character portrait of THIS same fluffy gray-and-white kitten. Preserve recognizable wide curious gray-green eyes, pink triangular nose, broad white blaze between the eyes, gray crown and cheeks, tufted large ears, and fluffy white chest.
Style/medium: refined Japanese character illustration with soft tactile painted shading, clear rounded silhouette and a few crisp delicate strokes. Friendly, calm, charming, not photorealistic and not generic clipart.
Composition/framing: single front-facing kitten head and upper chest centered, two tiny front paws visible. Entire head, ears and paws comfortably inside the central 66 percent of the canvas so it remains safe when masked to Android adaptive and iOS rounded-square icons. Strong readable face at 48 pixels. Flat warm cream background #F6F3EC filling the complete 1024x1024 square. No border and no pre-rounded canvas corners.
Color palette: natural warm white and slate-gray fur from reference, subtle pink nose and inner ears. 
Constraints: one cat only, no text, no letters, no watermark, no accessories, no money, no scene, no collage, no UI mockup. Deliver the actual finished square icon artwork.
```
